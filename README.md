# Программный модуль передачи управляющих воздействий

Данный репозиторий содержит программный модуль, использованный при экспериментальной проверке работы модульного всенаправленного конвейера.

Программа реализована на языке Python и выполняет функцию UDP-шлюза между верхним уровнем управления и исполнительными модулями конвейера.

## Назначение программы

Программный модуль принимает массив управляющих воздействий от MATLAB по протоколу UDP, разделяет его на группы для отдельных ячеек конвейера и передает сформированные пакеты на ESP-модули исполнительных ячеек.

## Основные функции

Программа выполняет следующие операции:

1. прием массива из 36 управляющих значений от MATLAB;
2. проверку размера входного UDP-пакета;
3. разделение массива на 9 групп по 4 значения;
4. формирование отдельного пакета для каждой ячейки конвейера;
5. добавление идентификатора ячейки и контрольной суммы;
6. передачу управляющих пакетов на ESP-модули;
7. отправку нулевых управляющих значений при отсутствии новых данных.
