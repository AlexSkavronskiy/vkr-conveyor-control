# Материалы к выпускной квалификационной работе

Данный репозиторий содержит материалы, использованные при разработке и экспериментальной проверке модульного всенаправленного конвейера.

В репозитории размещены программный модуль передачи управляющих воздействий, а также конструкторская документация на одну ячейку конвейера.

## Состав репозитория

- `main.py` — программный модуль передачи управляющих воздействий от верхнего уровня управления к исполнительным модулям конвейера;
- `Сборка Ячейки.cdw` — сборочный чертеж одной ячейки конвейера;
- `Спецификация Ячейки.spw` — спецификация одной ячейки конвейера.

## Программный модуль

Программный модуль реализован на языке Python и выполняет функцию UDP-шлюза между верхним уровнем управления и исполнительными модулями конвейера.

Программа принимает массив управляющих воздействий от MATLAB по протоколу UDP, разделяет его на группы для отдельных ячеек конвейера и передает сформированные пакеты на ESP-модули исполнительных ячеек.

Основные функции программы:

1. прием массива из 36 управляющих значений от MATLAB;
2. проверка размера входного UDP-пакета;
3. разделение массива на 9 групп по 4 значения;
4. формирование отдельного пакета для каждой ячейки конвейера;
5. добавление идентификатора ячейки и контрольной суммы;
6. передача управляющих пакетов на ESP-модули;
7. отправка нулевых управляющих значений при отсутствии новых данных.
